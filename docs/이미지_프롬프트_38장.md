# AI 리터러시 웹앱 — 이야기 이미지 프롬프트 (38장)

## 사용 방법 (ChatGPT 이미지 생성)

1. **ChatGPT 새 대화 하나에서 전부 만들기.** 같은 대화 안에서 만들어야 등장인물 얼굴과 그림체가 계속 비슷하게 유지돼요.
2. 맨 처음에 아래 **[0] 기본 설정**을 붙여넣고, **[0-1] 캐릭터 시트**부터 만들어요. 마음에 들 때까지 다시 만든 다음 진행해요.
3. 그다음 장면 프롬프트를 **한 번에 하나씩** 붙여넣어요. 인물이 달라지면 "캐릭터 시트와 똑같은 얼굴·옷으로 다시"라고 말해요.
4. 저장할 때 파일 이름을 **프롬프트 제목과 똑같이** 해요 (예: `story1-1.png`). 웹앱이 이 이름으로 그림을 찾아요.
5. 다 만든 그림은 작업 폴더 `assets/img/`에 넣어요. (맨 아래 "Claude Code에 보낼 문장" 참고)
